# Technology Stack

## Core Technologies
- **Language:** JavaScript (Vanilla ES6+)
- **Frontend:** HTML5, CSS3
- **Platform:** Progressive Web App (PWA)

## Architecture & Infrastructure
- **Persistence:** Browser Local Storage (Synchronous, client-side only)
- **Offline Support:** Service Workers (Cache API for asset persistence)
- **Manifest:** Web App Manifest for "Add to Home Screen" functionality

## Design & UI
- **Styling:** Vanilla CSS (Modularized per page)
- **Icons:** SVG-based category and action icons
- **Visual Source of Truth:** `Template-earn/` directory
